# Peugeot 307 VAN Monitor

Диагностическое Android-приложение для Peugeot 307 с RP5-PA-104 и Android-магнитолой RK3566 / CTC01_P01.

## Что делает v0.1

- запускает фоновый foreground service;
- умеет стартовать после загрузки Android;
- читает выбранную папку с `.txt` логами штатного CANBUS-приложения;
- разбирает кадры формата `2E CMD LEN DATA CHECKSUM`;
- проверяет checksum;
- отдельно фиксирует команды `0x20` (подрулевые кнопки);
- отслеживает изменения статусного кадра `0x01`;
- сохраняет компактный диагностический файл в `Downloads/Peugeot307VanMonitor`.

**Безопасность:** эта версия только читает уже существующий лог. Она ничего не передаёт в VAN/CAN и не управляет автомобилем.

## Сборка

GitHub Actions автоматически собирает debug APK после каждого push в `main`.
